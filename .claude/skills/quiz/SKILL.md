# /quiz — 変更内容の理解度チェック

**手順の本体は [.agents/skills/quiz/SKILL.md](../../../.agents/skills/quiz/SKILL.md)。まずそれを読んで、そのとおりに進める。**
Codex と共通の仕様にしてあるので、内容を変えるときはあちらを直すこと（ここには複製しない）。

Claude Code 固有の補足だけここに置く。

- 合格マーカーに書くツール名は `claude`。
- `/quiz` はユーザーが clone した対象リポジトリ内から実行する。共通手順の「0. clone したリポジトリを確認する」を必ず行う。
- PR 作成前に合格マーカーを確認する。未合格なら PR 作成を保留し、ユーザーに `/quiz` の実行を案内する。
- ユーザーの回答を待たずに自分で答えを埋めない。クイズはユーザー本人のためのもの。
