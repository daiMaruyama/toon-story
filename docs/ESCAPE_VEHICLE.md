# 脱出車両と出口

マップの担当者向け: 既存マップはこの変更では編集しません。レベル上の通行可能な床に `/Game/Items/EscapeVehicle/BP_EscapeVehicle`、車で到達できる出口に同フォルダの `BP_EscapeExit` を各1個配置してください。どちらも既存の `TBEscapeVehicle` / `TBEscapeExit` を継承する配置用 Blueprint です。ネイティブクラスを直接配置しても同じ外観になります。車両と出口の両方があるステージだけが脱出ルールに切り替わり、未配置の既存ステージは電池達成時の従来勝利を維持します。

- 車は既存の `SM_ToyCar_01` を使用します。前方はローカル +X、全長110cmです。走行判定は長さ110・幅80・高さ40cmのままで、外観は約110×49×49cmです。配置時の Actor の Z は床面+20cmを基準にします。
- 出口は既存の `SM_Central_Gates` を使用します。通過方向はローカル +X、門の幅は200cm、配置時の Actor の Z は床面+100cmが基準です。門の外観には衝突を持たせず、従来どおり `ExitArea` の重なりで脱出を判定します。
- 出口の判定範囲は `ExitArea` の Box Extent、外観の大きさ・位置は `Marker` で個別に調整できます。範囲を変更しても外観は自動で拡縮されません。車の判定幅に合わせ、出口までの経路と門の開口に余裕を確保してください。
- 収集電池は `/Game/ToyWorld/Meshes/SM_Battery_01` を使用します。既存の高さ12cm・底面位置を維持し、編集画面とプレイ中で同じ参照を適用します。

`/Game/CookLabels/PAL_EscapeVisuals` が上記3メッシュと配置用 Blueprint を明示的に AlwaysCook に指定します。素材パック全体を追加収録する設定は不要です。

コードで床と壁を作る検証用アリーナでは車両と出口も自動生成します。車両は `(-1500, -1000, 20)`、出口は `(2100, 1900, 100)` です。

両方配置したステージでは電池を集めると脱出フェーズに入り、残り時間は最低30秒に延長されます。おもちゃは車にインタラクトするか触れて搭乗し、最初の搭乗者が移動操作で運転します。降車はインタラクトの長押しです。車で出口に入ると搭乗者だけが脱出成功となります。脱出前の時間切れは人間の勝利です。

走行速度・旋回速度・降車の長押し秒数・操作距離は `Content/Data/DA_EscapeVehicle` で調整できます。車両の既定値はこのアセットを参照し、読み込めない場合は C++ の初期値を使います。脱出開始時の最低残り時間は `DA_TBRules` の試合設定で調整できます。

未確認: NPC による搭乗・運転、ネットワーク越しの操作・視点、実際のマップでの走行可能性。出口への経路と狭い場所をプレイテストして配置してください。
