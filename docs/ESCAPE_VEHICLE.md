# 仮の脱出車両

マップの担当者向け: 既存マップはこの変更では編集しません。レベル上の通行可能な床に `TBEscapeVehicle`、車で到達できる出口に `TBEscapeExit` を各1個配置してください。車両の幅は約110cmです。出口は `ExitArea` の Box Extent で範囲を調整できます。車両と出口の両方があるステージだけが脱出ルールに切り替わり、未配置の既存ステージは電池達成時の従来勝利を維持します。

コードで床と壁を作る検証用アリーナでは車両と出口も自動生成します。車両は `(-1500, -1000, 20)`、出口は `(2100, 1900, 100)` です。

両方配置したステージでは電池を集めると脱出フェーズに入り、残り時間は最低30秒に延長されます。おもちゃは車にインタラクトするか触れて搭乗し、最初の搭乗者が移動操作で運転します。降車はインタラクトの長押しです。車で出口に入ると搭乗者だけが脱出成功となります。脱出前の時間切れは人間の勝利です。

走行速度・旋回速度・降車の長押し秒数・操作距離は `Content/Data/DA_EscapeVehicle` で調整できます。車両の既定値はこのアセットを参照し、読み込めない場合は C++ の初期値を使います。脱出開始時の最低残り時間は `DA_TBRules` の試合設定で調整できます。

未確認: NPC による搭乗・運転、ネットワーク越しの操作・視点、実際のマップでの走行可能性。出口への経路と狭い場所をプレイテストして配置してください。
