# 受入テスト

ルールの数値は Notion を参照し、以下の数値例は検証用設定として扱ってください。

本一覧は制作PCで実施するものです。通常通信→遅延・ロス→別PC→Steam別回線の順で確認。ホスト役を人間／おもちゃで入れ替えてください。詳細な実施結果はまだありません。

| ID | 手順 | 合格条件 |
|---|---|---|
| B01 | Development Editor / Win64をビルド | UHT・C++・リンク成功 |
| B02 | Arena・照明を作成してPlay | 床・壁・箱・8個の球・HUD表示 |
| B03 | Windows Developmentをパッケージ化 | Arena同梱、入力有効 |
| L01 | 2人でTBRules 1 1 600 5、全員R、ホストF5 | 1対1で開始 |
| L02 | 人数不足／未Ready／非ホスト開始 | 開始しない |
| L03 | 非ホストが人数変更、定員を超える参加 | 設定変更不可、定員超過拒否 |
| L04 | MaxPlayersを変更して部屋作成・人数設定・満員参加 | 募集枠・設定可能人数・参加拒否が同じ定員に従う |
| G01 | おもちゃを見る | 移動・ジャンプ・視点操作停止 |
| G02 | 視線を外す | 次のサーバー評価で解除。意図的な0.25秒待機なし |
| G03 | 視線が壁で遮られる／画面外 | 凍結しない、または解除 |
| G04 | 頭・胴・足の1点だけ見える | 凍結する |
| G05 | ジャンプ上昇中に見られる | XYと上昇速度が止まり、落下する |
| G06 | 落下中に見られる | XYは止まり、下降速度を維持。落下再開時の速度リセットなし |
| G07 | 凍結したまま着地する | 床を貫通せず、その位置で操作不能 |
| G08 | 落下途中で視線が外れる | 落下継続、空中操作が通常へ戻る |
| G09 | 2人間のうち片方だけ見る | 1人でも見ている間は停止 |
| G10 | 人間が静止してマウスだけ動かす | サーバーの視線も更新される |
| C01 | 正面・範囲内の対象をEで掴む | Free→Grabbed→Carried。凍結の有無を条件にしない |
| C02 | 遠距離／壁越し／背面から掴む | 不成立 |
| C03 | 人間2人が同時に同じ対象を掴む | 運搬者が1人だけになる |
| C04 | 箱の操作位置で設定時間だけ長押し収納 | 完了後Boxed。途中では勝利扱いにしない |
| C05 | 収納中にEを離す／範囲外へ | 中断しておもちゃを落とす |
| D01 | 仲間を収納し、箱外で救助を完了 | 仲間が箱外へ移動してFreeになる |
| D02 | 救助者数とAdditionalRescuerBonusを変える | 設定した加速割合で進捗が増える。0なら人数で加速しない |
| D03 | 救助者が減る／0になる | 残る限り速度だけ変更、0なら進捗リセット |
| D04 | 箱外の救助先を塞いで救助する | 埋まらず、移動できない対象は残る。空けて再救助できる |
| D05 | おもちゃが救助中に人間とおもちゃの画面を比較する（通常HUDとtb.DebugHUD） | 進捗はおもちゃ側だけに表示。人間側に救助開始メッセージ・進捗・警報音が出ない |
| I01 | 球へ3秒触れる。Eは押さない | 1個取得、共有数+1 |
| I02 | 途中で離れる→再接触 | 0からやり直し |
| I03 | 接触1秒→見られたまま5秒→解除 | 凍結中は約33%保持。解除後残り約2秒で取得 |
| I04 | 凍結中に落下などで接触がなくなる | 進捗0 |
| I05 | 接触中に掴まれる／収納される | 対象・進捗をリセット |
| I06 | 人間が球に接触 | 取得不可 |
| I07 | 2人のおもちゃが同時に3秒接触 | 加算は1。合算加速しない |
| W01 | 必要数を取得せずに時間切れ | 人間勝利 |
| W02 | 全員Boxed | 人間勝利 |
| W03 | 時間内に必要数を取得 | おもちゃ勝利 |
| W04 | 最後の収納と期限が競合 | 判定時に期限到達なら時間切れ優先 |
| X01 | bAllowInterference=falseでApplyInterruption | 状態を変更しない |
| X02 | trueでサーバーから収納／救助中に妨害 | それぞれ適切に中断 |
| N01 | Nullで2台のHost→Find→Join | 同じ部屋へ接続 |
| N02 | Steam別アカウント・別回線 | 作成・検索・参加成立 |
| N03 | Leave→再Host→再Join | 古い部屋が残らず再接続 |
| N04 | 満員・古い検索結果・試合中参加 | エラーを表示。試合中参加は拒否 |
| N05 | 両陣営に残員がいる状態で非ホストが切断 | 試合とホストの部屋が維持される |
| N06 | 運搬側／運ばれる側が切断 | 運搬参照を整理。残ったキャラが操作可能で、両陣営が残れば継続 |
| N07 | 最後の人間／最後のおもちゃが切断 | 相手陣営が勝利し、部屋は自動解散しない |
| N08 | ホスト強制終了 | NetworkFailure後に退出処理 |
| N09 | 試合開始後に別PCで再検索・招待参加 | 検索から消え、古い検索結果や招待からも途中参加不可 |
| N10 | 自由なおもちゃが退出し、残り全員が収納済み | 退出者を除いて全員収納を判定し人間勝利 |
| N11 | 試合終了後、ホストがReturn together to lobby→全員Ready→Startを繰り返す | 同じ接続・メンバー・設定で再戦でき、収集物・収納・運搬・凍結・救助・時間がリセットされる |
| N12 | 試合中または非ホストからTBLobbyを要求 | 試合や結果をリセットしない |
| N13 | 再戦ロビーへ戻った後、空き枠がある部屋を検索・参加 | 同じ部屋が再び見つかり、ロビー中だけ参加できる |
| N14 | 結果画面で非ホストがLeave room | 退出者だけ離れ、残ったメンバーは再戦できる。減った人数に合わせてホストが設定を変更する |

## 最優先の実機確認

凍結用CustomMovementModeのサーバー補正、箱外への救助移動、おもちゃ同士の衝突、キャラと球のOverlap、凍結境界での進捗停止。数式テストだけではこれらを確認できません。
