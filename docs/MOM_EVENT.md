# ママが来る！

試合中の自然発生イベントです。人間が指定エリアへ行き、連続して滞在すると説得成功になり、通常の試合へ戻ります。間に合わなければ人間の負け（おもちゃの勝ち）で試合が終了します。

- 人間が1人でも範囲内にいる間は、ママ到着までのカウントを停止して説得ゲージを進めます。
- 複数人がいても速度は増えません。1人残っていれば交代できます。
- 全員が範囲を出ると説得ゲージは0に戻り、到着カウントを再開します。
- おもちゃ、別の階、壁を隔てた場所からは説得できません。
- 隠れる準備中・ロビー・結果画面では発生せず、再試合へ状態を持ち越しません。
- 人間陣営を操作するプレイヤーが1人以上いる試合だけで発生します。人間がNPCのみなら抽選対象外です。イベント中に最後の人間プレイヤーが抜けた場合も、敗北を発生させず中止します。
- ママイベント中は他の自然イベントの抽選・明示的な発火を停止し、終了・中止後から共通クールダウンを開始します。瞬時に終わるイベントは従来どおり発火直後からCDを数えます。
- 残り時間・占有・進捗・失敗判定はサーバーで管理し、クライアントへ複製します。

## DB設定

`Content/Data/DA_TBRules` →「イベント」→「ママが来る！」で調整します。

| 設定 | 初期値 |
| --- | --- |
| ママ到着までの秒数 | 45秒 |
| 説得に必要な連続滞在秒数 | 5秒 |
| 指定範囲の半径 | 60cm |
| 足元の許容高さ | 120cm |

位置はマップ上の `TBMomArrivalZone` の原点で指定します。判定範囲は床上の円柱です。原点は床へ置き、Actorの拡大ではなくDBの半径で広さを変えます。足元から原点への高低差を使い、範囲内でも遮蔽物がある場合は対象外にします。

「イベント候補」へ `TBMomArrivalEvent` を登録済みです。発生確率とクールダウンは既存イベントと共通です。指定エリアがないマップでは抽選対象になりません。複数地点を置いた場合は1地点をランダム選択し、同時に複数のママイベントは開始しません。成功しても試合そのものは終了しません。

## 設置と表示

HouseとDemoには、ユーザーの設定依頼により `Content/Events/Mom/BP_MomArrivalZone` を各1地点配置済みです。ほかのステージへ追加する場合は次の手順を使います。配置していないマップでは発生しません。

1. 本体をビルドし、対応するContentを `git submodule update --init --recursive` で取得してエディタを開きます。担当者の未保存・未コミットのContent作業は、取得前に保存・保護してください。
2. Content Browserの `Events/Mom/BP_MomArrivalZone` を、作業中のレベルの床へドラッグします。赤点線と仮キューブは設定済みなので、素材の手動割り当ては不要です。
3. Actorの原点を床の高さに合わせ、Scaleを `(1,1,1)` にします。エディタ上の点線が家具や壁に食い込まず、人間が入れることを確認します。表示範囲と判定半径はDBが基準です。
4. Detailsの「ママが来る！」→「この地点を候補にする」をオンにします。複数地点を配置すると、発生時にそのうち1地点が選ばれます。
5. `Data/DA_TBRules` の「イベント候補」に `TBMomArrivalEvent` が入っていることを確認します（この変更に含むDAでは登録済み）。別途調整中のDAへ組み込む場合は、既存候補を残したまま追加してください。
6. 人間陣営にプレイヤーを1人以上入れ、範囲への到達・ゲージ・範囲を出た場合の挙動を確認してから、担当者側でレベルを保存します。

保存済みの配置はHouse外周側 `Gameplay/Events/Mom/MomArrival_Entrance`（約 `(-300, -650, 20.95)`）とDemo寝室側 `MomArrival_Bedroom`（約 `(-450, -175, -7)`）です。Scaleは `(1,1,1)`、候補を有効にし、既存の家具配置を保持しています。以前のDemo参考位置 `(-490, -25, -7)` は範囲の周囲が家具に近いため変更しました。床・人間の立ち位置・イベント開始・説得進捗は `ToonStory.Events.AuthoredMom` で両マップを検証できます。

中心はテクスチャなしの仮キューブです。イベント中だけ範囲に赤い点線を表示します。全員の画面に赤字の残り時間、人間には追加の案内と、説得中は箱収納と同じ形式のゲージを表示します。

手早く確認したいときは、DAのイベント候補を一時的にこのイベントだけにし、毎秒の発生確率を1にして、通常の試合を開始します。確認後は候補と確率を戻してください。

## バージョン互換性

現在のBuildTagは `ToonStory_LobbyEmotes_20261102` です。ロビーのエモート同期にフェーズ情報を追加したため、以前の `ToonStory_RandomItems_MomEvent_20261101` を含む旧タグの部屋は検索結果から除外し、招待・参加入口でも拒否します。同じ配布物は同じタグに揃えてください。これは部屋の検索・参加前チェックであり、コンソールのIP直接接続やUE自体のネットワーク互換性を保証するものではありません。
