# ママが来る！

試合中の自然発生イベントです。人間が指定エリアへ行き、連続して滞在すると説得成功になり、通常の試合へ戻ります。間に合わなければ人間の負け（おもちゃの勝ち）で試合が終了します。

- 人間が1人でも範囲内にいる間は、ママ到着までのカウントを停止して説得ゲージを進めます。
- 複数人がいても速度は増えません。1人残っていれば交代できます。
- 全員が範囲を出ると説得ゲージは0に戻り、到着カウントを再開します。
- おもちゃ、別の階、壁を隔てた場所からは説得できません。
- 隠れる準備中・ロビー・結果画面では発生せず、再試合へ状態を持ち越しません。
- 残り時間・占有・進捗・失敗判定はサーバーで管理し、クライアントへ複製します。

## DB設定

`Content/Data/DA_TBRules` →「イベント」→「ママが来る！」で調整します。

| 設定 | 初期値 |
| --- | --- |
| ママ到着までの秒数 | 45秒 |
| 説得に必要な連続滞在秒数 | 5秒 |
| 指定範囲の半径 | 60cm |
| 足元の許容高さ | 120cm |

位置はマップ上の `TBMomArrivalZone` の原点で指定します。判定範囲は床上の円柱です。原点は床へ置き、Actorの拡大ではなくDBの半径で広さを変えます。足元から原点への高低差を使い、範囲内でも遮蔽物がある場合は対象外にします。

「イベント候補」へ `TBMomArrivalEvent` を登録済みです。発生確率とクールダウンは既存イベントと共通です。指定エリアがないマップでは抽選対象になりません。複数地点を置いた場合は1地点をランダム選択し、同時に複数のママイベントは開始しません。成功しても試合そのものは終了しません。

## 設置と表示

Outlinerの `Gameplay/Events/MomArrival_StageEdge` に配置しています。

- House：外周側、座標 `(-300, -650, 21)`。
- Demo：寝室側、座標 `(-490, -25, -7)`。

中心はテクスチャなしの仮キューブです。イベント中だけ範囲に赤い点線を表示します。全員の画面に赤字の残り時間、人間には追加の案内と、説得中は箱収納と同じ形式のゲージを表示します。

手早く確認したいときは、DAのイベント候補を一時的にこのイベントだけにし、毎秒の発生確率を1にして、通常の試合を開始します。確認後は候補と確率を戻してください。
