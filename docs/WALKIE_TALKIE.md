# トランシーバー

試合開始時のランダムアイテムとして、候補地点から2台一組で配置する。必要な出現数の残りが2台未満、または両方の安全な設置場所を確保できない場合は配置しない。既存マップの編集は不要。

人間・おもちゃのどちらも、近づいてインタラクトを長押ししている間、相方から自分のボイスチャットを送信できる。キーを離す、操作不能になる、離れる、試合が終わる、または相方が消えると送信を終了する。受信機が送信中はその受信機からの音は鳴らない。

`DA_WalkieTalkie` で操作距離、受信音の届く距離、高音域の制限を調整する。`DA_TBRules` のランダム配置で出現ON/OFF、重み、床での変換を変更できる。出現数は2台分を消費する。

現在のボイスチャットは話者につき再生系統が1つのため、受信機の範囲内の聞き手については話者の声の再生位置を受信機へ切り替える。話者の元の位置と受信機から同時に鳴らすことはできない。また、周囲の環境音や第三者の声は送信しない。音声通信の確認はマイク付きの複数クライアントで行う必要がある。
