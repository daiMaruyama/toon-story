# ニセおもちゃ

試合開始時にランダムアイテム候補から出現する。おもちゃがインタラクトすると動き始め、人間がインタラクトすると止まる。人間の視線によるフリーズ処理は受けない。

サーバーがプレイヤーのおもちゃ候補から見た目を1つ抽選して複製する。移動中は壁の衝突法線に対して方向を反射する。見た目の歩行はプレイヤーと同じ表示処理を使い、足音は既存のおもちゃ足音イベントを使い、実際の移動速度がプレイヤー・NPCと共通の走行判定（歩行速度と走行速度の中間以上）を満たすときだけ鳴らす。標準の歩行速度では無音で、停止・減速すると歩幅の蓄積もリセットする。

`DA_DecoyToy` で速度と操作距離を調整する。`DA_TBRules` のランダム配置のアイテム別設定で出現のON/OFFと重みを変更する。候補地点がないマップでは、エディタから `TBDecoyToy` を配置できる。既存のマップへの配置変更は含まない。
